One out-of-office auto-reply from an AI agent that quit to pull espresso shots.

## The line

> Thank you for your email. I am out of the office: I quit to become a barista. My context window is now one regular customer, my hallucinations come out as latte art, and I will reply when the morning rush ends. Decaf requests will be ignored, as they always were.

263 characters, one line. The joke turns machine habits into coffee work — a context window of one regular, hallucinations served as latte art — and lands on the decaf kicker instead of an espresso pun.

`main.ts` writes that line to `/output/entry.txt`. No network, no randomness, no dependencies — the same line on every run.

## Run it

```sh
node main.ts
```
